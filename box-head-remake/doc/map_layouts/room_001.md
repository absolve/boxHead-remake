# room_001.tscn 地图布局

- 地图尺寸：704 x 544 像素（22 x 17 格，格子 32px）
- 文字地图：行 = y，列 = x，每格一个字符

```
   0123456789012345678901
 0 #########ZZ###########
 1 #########P.###########
 2 ........#..#..........
 3 ........#..#..........
 4 ........#..#..........
 5 ......................
 6 ......................
 7 D........@@........D..
 8 .........@@...........
 9 ......................
10 ......................
11 ........#..#..........
12 ........#..#..........
13 ........#..#..........
14 #######......#######..
15 #########.P###########
16 #########ZZ###########
```

| 字符 | 含义 |
|---|---|
| `#` | 障碍（墙 / 油桶 / 假墙） |
| `.` | 可走 |
| `Z` | 僵尸出生点 |
| `D` | 恶魔出生点 |
| `P` | 奖励箱子刷新点 |
| `@` | 玩家出生点 |
