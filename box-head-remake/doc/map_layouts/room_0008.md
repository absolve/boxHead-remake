- 文字地图：行 = y，列 = x，每格一个字符

| 字符 | 含义 |
|---|---|
| `#` | 障碍（墙 / 油桶 / 假墙） |
| `.` | 可走 |
| `Z` | 僵尸出生点 |
| `D` | 恶魔出生点 |
| `P` | 奖励箱子刷新点 |
| `@` | 玩家出生点 |
