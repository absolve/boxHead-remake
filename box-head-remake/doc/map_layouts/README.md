# 房间布局文档（map_layouts）

这里的每个 `room_XXXX.md` 是**对应房间场景的布局快照**，由 `tools/dump_layout.tscn`
从 `.tscn` 实际数据导出，用来核对「原版地图 / 场景数据 / 运行时行为」三者是否一致。

## 文件

| 文件 | 内容 |
| --- | --- |
| `room_001.md` ~ `room_0018.md` | 一个房间一份：尺寸 + 字符画地图 + 图例统计 |

## 字符画图例

行 = y，列 = x，每格一个字符：

| 字符 | 含义 |
| --- | --- |
| `.` | 可走地面 |
| `#` | 障碍（`wallObstacles` 静态障碍格；油桶/假墙等动态障碍也会标在这里） |
| `@` | 玩家出生点 |
| `Z` | 僵尸出生点 |
| `D` | 恶魔出生点 |
| `P` | 奖励箱子刷新点 |
| `1` / `2` | 原版玩家标记（本项目忽略，玩家固定在地图中心 2×2） |

## 原版标记样式（从图片重建房间时用）

原版地图编辑器用「彩色圆圈 + 黑色字母」标出生点，`tools/build_rooms.py` 就按这套颜色识别：

| 圆圈颜色 (RGB) | 字母 | 含义 | 生成的东西 |
| --- | --- | --- | --- |
| `(153,153,153)` 灰 | Z | 僵尸出生点 | `map_sign` `type = 701` |
| `(255,0,0)` 纯红 | D | 恶魔出生点 | `map_sign` `type = 702` |
| `(255,51,0)` 红橙 | P | 奖励箱子刷新点 | `map_sign` `type = 703` |
| `(255,102,0)` 橙 | B | 油桶 | `barrelPoint` → `barrel_obj.tscn` |
| `(255,255,204)` 淡黄 | W | 墙壁 | `wallPoint` → `wall_obj.tscn` |
| `(118,110,227)` 紫 + 深蓝箭头 | 1 / 2 | 玩家标记 | **忽略**（玩家固定在地图中心 2×2）|
| `(68,68,195)` / `(128,128,255)` 蓝 | — | 静态障碍（柱子） | `wallObstacles` 格坐标 |

注意：蓝色只有圆圈内部/柱身才算障碍，白色高光部分是纯美术，不算碰撞。

## 重新生成

改完房间场景后重新导出（以 room_0005 为例）：

```powershell
$env:DUMP_ROOM = "res://scene/level/room_0005.tscn"
godot --headless --path box-head-remake res://tools/dump_layout.tscn --quit-after 600
```

批量导出全部房间见 `tools/` 下的脚本说明。
